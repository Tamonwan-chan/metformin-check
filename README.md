# 💊🩺 ระบบคัดกรองขนาดยา Metformin เกินเกณฑ์ (สำหรับผู้ป่วยที่ได้ยา Dolutegravir)
### เครื่องมือตรวจเช็กประวัติสั่งยาประจำเดือนเพื่อความปลอดภัยของผู้ป่วย
### พัฒนาโดย ภญ.ธมลวรรณ จันทร์แก้ว กลุ่มงานเภสัชกรรมและคุ้มครองผู้บริโภค โรงพยาบาลสันกำแพง

เครื่องมือนี้ถูกสร้างขึ้นมาเพื่อให้สามารถนำไฟล์ Excel ที่ดึงจากระบบโรงพยาบาล (HIS) มาตรวจหาเคสคนไข้ที่ได้ยา **Dolutegavir (DTG) ร่วมกับยา Metformin เกินเกณฑ์ปลอดภัย (1,000 มก./วัน)**

---

## 🔒 ปลอดภัยต่อข้อมูลผู้ป่วย 100% (ข้อมูลไม่รั่วไหล)
> [!IMPORTANT]
> **ระบบนี้ทำงานภายในเครื่องคอมพิวเตอร์ของคุณเท่านั้น (Client-Side Only)**
> * เมื่อลากไฟล์ Excel เข้ามาในหน้าเว็บ การคำนวณทั้งหมดจะเกิดขึ้นบนเบราว์เซอร์ (Chrome/Edge/Safari) ของคุณทันที 
> * **ไม่มีการอัปโหลดหรือส่งข้อมูลผู้ป่วย (ชื่อ, HN, ประวัติการใช้ยา) ออกไปยังอินเทอร์เน็ตภายนอก**

## 🚀 วิธีใช้งานง่ายๆ 3 ขั้นตอน

### ขั้นตอนที่ 1: ดึงข้อมูลเป็นไฟล์ Excel
ขอให้แผนก IT หรือผู้ดูแลระบบรันคำสั่ง **SQL** ด้านล่างนี้ในระบบ HOSxP เพื่อดึงข้อมูลประวัติสั่งยาของเดือนที่ต้องการ และส่งออก (Export) เป็นไฟล์ Excel (`.xlsx` หรือ `.xls`)

### ขั้นตอนที่ 2: เปิดโปรแกรมและลากไฟล์วาง
1. เปิดหน้าเว็บตรวจยาผ่านลิงค์หรือโปรแกรมที่โหลดไว้
2. ลากไฟล์ Excel ที่ดึงมาในขั้นตอนที่ 1 โยนใส่ช่องสีฟ้าบนหน้าจอ (หรือคลิกเพื่อเลือกไฟล์จากคอมพิวเตอร์)

### ขั้นตอนที่ 3: ดูผลลัพธ์และสั่งพิมพ์รายงาน
* **🔴 รายการสีแดง (เกินเกณฑ์):** ระบบจะคัดกรองผู้ป่วยที่ทาน Metformin เกิน 1,000 มก./วัน ออกมาทันที สามารถติ๊กเครื่องหมายถูกเพื่อติดตามงาน และกดปุ่ม **🖨️ พิมพ์ / บันทึกเป็น PDF** เพื่อนำส่งแพทย์แก้ไขขนาดยา
* **🟡 รายการสีเหลือง (ต้องตรวจมือ):** รายการที่ระบบอ่านวิธีใช้ยาไม่ได้ (เช่น แพทย์พิมพ์อิสระ หรือช่องวิธีใช้ว่าง) เพื่อให้เภสัชกรเปิดตรวจสมุดประวัติคนไข้อีกครั้งเพื่อความปลอดภัย

## 📊 คำสั่ง SQL สำหรับดึงข้อมูล (สำหรับรันในฐานข้อมูลโรงพยาบาล)
คุณสามารถคัดลอกโค้ดด้านล่างนี้ไปดึงข้อมูล: 

```sql
SELECT
    v.vstdate AS 'วันที่มารับบริการ',
    v.hn AS 'HN',
    v.vn AS 'VN',
    CONCAT(p.pname, p.fname, ' ', p.lname) AS 'ชื่อ-นามสกุล',
    d.icode AS 'รหัสยา',
    d.name AS 'ชื่อยา',
    o.qty AS 'จำนวนยา',
    -- ดึงวิธีใช้ยาจากตาราง drugusage (แสดงทั้งบรรทัดที่ 1, 2, 3 มารวมกัน)
    CONCAT(u.name1, ' ', IFNULL(u.name2, ''), ' ', IFNULL(u.name3, ''), IFNULL(u.shortlist, '')) AS 'วิธีใช้ยา'
FROM vn_stat v
LEFT JOIN patient p ON v.hn = p.hn
LEFT JOIN opitemrece o ON v.vn = o.vn
LEFT JOIN drugitems d ON o.icode = d.icode
LEFT JOIN drugusage u ON o.drugusage = u.drugusage -- เชื่อมตารางวิธีใช้ยาที่นี่
WHERE v.vstdate BETWEEN '2026-06-01' AND '2026-06-30' /* <-- เปลี่ยนช่วงวันที่ตรงนี้ */
  AND v.vn IN (
      -- เงื่อนไขที่ 1: ต้องมียา Metformin (รหัส 1000184) ใน visit นั้น
      SELECT distinct vn 
      FROM opitemrece 
      WHERE icode = '1000184'
  )
  AND v.vn IN (
      -- เงื่อนไขที่ 2: ต้องมีกลุ่มยา Dolutegravir / KOCITAF / TLD ใน visit นั้นด้วย
      SELECT distinct vn 
      FROM opitemrece 
      WHERE icode IN ('166011', '1650024', '1670018', '1680003', '1650014', '1650040')
  )
  -- กรองแสดงเฉพาะรายการยาที่เราสนใจในใบสั่งยา
  AND o.icode IN ('1000184', '166011', '1650024', '1670018', '1680003', '1650014', '1650040')
ORDER BY v.vstdate DESC, v.vn, o.icode
```

*(หมายเหตุ: รหัสยา `icode` ในคิวรีนี้เป็นรหัสมาตรฐานของระบบ หากโรงพยาบาลใช้รหัสอื่นสามารถแจ้งฝ่าย IT ให้แก้ไขตัวเลขในบรรทัด `icode = ...` หรือ `icode IN (...)` ได้ตามจริง)*

## ⚙️ เกณฑ์การคำนวณและประเมินขนาดยา
ระบบอิงตามขนาดยา Metformin เม็ดละ **500 มก.** หากผู้ป่วยทานเกิน 2 เม็ด/วัน (เกิน 1,000 มก./วัน) ระบบจะเตือนทันที:

| ตัวอย่างวิธีใช้ในไฟล์ | ความหมาย | จำนวนเม็ด/วัน | ขนาดมิลลิกรัม/วัน | ผลการตรวจเช็ก |
|---|---|---|---|---|
| `1x1` หรือ `1x1 pc` | ทานครั้งละ 1 เม็ด วันละ 1 ครั้ง | 1 เม็ด | 500 มก. | **ปกติ ✅ (ผ่าน)** |
| `1x2` หรือ `1x2 pc` | ทานครั้งละ 1 เม็ด วันละ 2 ครั้ง | 2 เม็ด | 1000 มก. | **ปกติ ✅ (สูงสุดตามเกณฑ์)** |
| `0.5x1` | ทานครั้งละ ครึ่งเม็ด วันละ 1 ครั้ง | 0.5 เม็ด | 250 มก. | **ปกติ ✅ (ผ่าน)** |
| `1x3` | ทานครั้งละ 1 เม็ด วันละ 3 ครั้ง | 3 เม็ด | 1500 มก. | **เกินเกณฑ์ 🔴 (ต้องแก้ไข)** |
| `2x2` | ทานครั้งละ 2 เม็ด วันละ 2 ครั้ง | 4 เม็ด | 2000 มก. | **เกินเกณฑ์ 🔴 (ต้องแก้ไข)** |
| `2-0-1` | ทาน เช้า 2 เม็ด - กลางวัน 0 เม็ด - เย็น 1 เม็ด | 3 เม็ด | 1500 มก. | **เกินเกณฑ์ 🔴 (ต้องแก้ไข)** |
| *(เว้นว่างไว้)* หรือ `- -` | ไม่มีข้อมูลวิธีใช้ หรือปริมาณเป็น 0 | - | - | **ส่งไปตรวจมือ 🟡 (ข้อมูลไม่ครบ)** |
| *พิมพ์ข้อความอิสระ* | อ่านด้วยโปรแกรมไม่ได้ เช่น "กินตามอาการ" | - | - | **ส่งไปตรวจมือ 🟡 (ไม่ปลอดภัย)** |
| *สั่งยาซ้ำหลายบรรทัด* | สั่งยา Metformin มากกว่า 1 รายการในครั้งเดียว | - | - | **ส่งไปตรวจมือ 🟡 (ต้องแยกคำนวณ)** |
